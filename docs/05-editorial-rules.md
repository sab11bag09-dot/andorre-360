# Editorial Rules

> Les règles éditoriales d’ANDORRE 360.

Ce document définit les principes qui encadrent la production, la validation, la publication et la mise à jour des contenus.

Ces règles s’appliquent :

- aux journalistes ;
- aux agents IA ;
- aux workflows automatisés ;
- aux publications sur tous les canaux.

Elles priment toujours sur les recommandations d’un modèle d’intelligence artificielle.

---

# Mission éditoriale

ANDORRE 360 a pour mission de produire une information :

- exacte ;
- compréhensible ;
- utile ;
- traçable ;
- rapide sans être précipitée ;
- respectueuse des personnes ;
- adaptée à son public.

La rapidité ne justifie jamais une baisse du niveau de fiabilité.

La publication n’est pas l’objectif final.

L’objectif est de permettre au public de comprendre ce qui s’est passé, pourquoi cela compte et ce qui peut encore évoluer.

---

# Principes fondamentaux

## Exactitude

Toute information publiée doit reposer sur des éléments identifiables.

Une information incertaine doit être présentée comme incertaine.

Une hypothèse ne doit jamais être formulée comme un fait établi.

## Traçabilité

Toute affirmation factuelle significative doit pouvoir être reliée à :

- un Fact ;
- un Claim ;
- une Evidence ;
- une Source identifiable.

Un contenu sans provenance suffisante ne doit pas être publié automatiquement.

## Clarté

Le lecteur doit comprendre immédiatement :

- ce qui s’est passé ;
- qui est concerné ;
- où cela s’est produit ;
- quand cela s’est produit ;
- pourquoi cela est important.

Le langage administratif, technique ou institutionnel doit être reformulé sans déformer le sens.

## Indépendance

Une Source officielle est une Source importante.

Elle n’est pas automatiquement une vérité complète.

Les communiqués, déclarations et publications institutionnelles doivent être distingués des faits vérifiés indépendamment.

## Responsabilité humaine

Les journalistes restent responsables de la ligne éditoriale.

Un agent IA peut proposer, préparer ou exécuter une action autorisée.

Il ne peut pas redéfinir seul les règles éditoriales.

---

# Hiérarchie de l’information

Un contenu doit présenter les informations dans l’ordre de leur importance journalistique.

Le début d’un Article doit répondre aussi rapidement que possible aux questions essentielles :

- quoi ;
- qui ;
- où ;
- quand ;
- pourquoi ;
- comment.

Toutes ces réponses ne sont pas toujours disponibles.

Les informations manquantes doivent être signalées, jamais inventées.

Le contexte doit venir après les éléments nouveaux, sauf lorsqu’il est indispensable à leur compréhension.

---

# Séparation entre faits et déclarations

Le système doit toujours distinguer :

- ce qui est observé ;
- ce qui est affirmé ;
- ce qui est confirmé ;
- ce qui est contesté ;
- ce qui reste inconnu.

Exemple :

À éviter :

> La commune fermera la route demain.

À privilégier lorsque seule une annonce est disponible :

> La commune annonce que la route sera fermée demain.

Cette distinction permet de ne pas transformer automatiquement une déclaration en fait accompli.

---

# Niveaux de confiance

Chaque Story et chaque Fact peut posséder un niveau de confiance.

Le niveau de confiance dépend notamment :

- de la nature de la Source ;
- du nombre de Sources concordantes ;
- de la qualité des Evidences ;
- de l’existence de contradictions ;
- de la fraîcheur de l’information ;
- du contexte éditorial.

Le niveau de confiance ne doit jamais être déduit uniquement de la réputation générale d’une Source.

Une Source fiable peut se tromper.

Une Source secondaire peut fournir une information exacte.

---

# Sources

## Sources primaires

Une Source primaire fournit une information directe.

Exemples :

- texte officiel ;
- décision administrative ;
- déclaration enregistrée ;
- donnée publique ;
- document original ;
- témoignage direct ;
- résultat publié par l’organisateur.

Les Sources primaires doivent être privilégiées lorsqu’elles sont disponibles.

## Sources secondaires

Une Source secondaire rapporte ou analyse une information produite ailleurs.

Exemples :

- média ;
- agence ;
- rapport de synthèse ;
- publication d’un tiers.

Une Source secondaire peut être utilisée pour contextualiser ou confirmer.

Elle ne doit pas être présentée comme l’origine directe d’une information lorsqu’elle ne l’est pas.

## Sources anonymes

L’utilisation de Sources anonymes exige une validation humaine.

Le système automatisé ne doit pas publier une information sensible reposant uniquement sur une Source anonyme.

L’identité réelle de la Source doit être connue d’un responsable éditorial lorsque cela est possible.

## Réseaux sociaux

Une publication sur un réseau social ne constitue pas automatiquement une confirmation.

Elle doit être attribuée clairement.

L’identité du compte, son authenticité et le contexte doivent être vérifiés.

Une capture d’écran sans provenance suffisante ne constitue pas une preuve fiable.

---

# Vérification

Avant publication, le système doit vérifier autant que possible :

- les noms ;
- les fonctions ;
- les dates ;
- les heures ;
- les lieux ;
- les montants ;
- les unités ;
- les citations ;
- les résultats ;
- les liens ;
- la cohérence chronologique.

Une information étonnante, sensible ou potentiellement dommageable nécessite un niveau de vérification supérieur.

Plus une affirmation est grave, plus le niveau de preuve exigé doit être élevé.

---

# Contradictions

Les contradictions ne doivent jamais être masquées.

Lorsqu’elles existent, le système doit :

- conserver les différentes versions ;
- identifier leurs Sources ;
- signaler le désaccord ;
- éviter de choisir arbitrairement ;
- demander une validation humaine si nécessaire.

Un Article peut expliquer qu’une information reste contestée.

Il ne doit pas créer artificiellement une certitude.

---

# Corrections

Une erreur publiée doit être corrigée rapidement.

La correction doit :

- identifier précisément ce qui était incorrect ;
- remplacer l’information erronée ;
- conserver la trace de la version précédente ;
- indiquer la correction au lecteur lorsqu’elle est significative ;
- mettre à jour les canaux concernés.

Une correction ne doit jamais être effectuée silencieusement lorsque l’erreur modifie substantiellement le sens de l’Article.

Une précision mineure de forme peut être corrigée sans note publique, mais doit rester historisée dans le système.

---

# Mises à jour

Une Story peut évoluer après publication.

Lorsqu’un nouveau Fact apparaît, le système doit déterminer s’il faut :

- mettre à jour l’Article existant ;
- publier une nouvelle version ;
- créer un nouvel Article ;
- ajouter une note de mise à jour ;
- retirer une information devenue incorrecte.

Une mise à jour ne doit pas effacer l’historique de l’événement.

Les changements significatifs doivent être datés.

---

# Rédaction en français

Le français est la langue éditoriale principale d’ANDORRE 360.

Les contenus doivent être rédigés dans un français :

- clair ;
- naturel ;
- précis ;
- accessible ;
- grammaticalement correct ;
- adapté au contexte andorran.

Le système ne doit pas produire une traduction littérale du catalan, de l’espagnol ou de l’anglais.

Il doit comprendre les Facts dans leur langue d’origine puis les rédiger naturellement en français.

À éviter :

- calques syntaxiques ;
- faux amis ;
- structures administratives traduites mot à mot ;
- formulations artificielles ;
- conservation inutile de termes étrangers.

Les noms officiels peuvent être conservés dans leur langue d’origine lorsqu’ils constituent une dénomination propre.

Une traduction ou une explication peut être ajoutée si elle aide le lecteur.

---

# Style rédactionnel

## Ton

Le ton doit être :

- factuel ;
- sobre ;
- direct ;
- professionnel ;
- compréhensible.

Le système doit éviter :

- le sensationnalisme ;
- l’exagération ;
- le militantisme implicite ;
- le ton promotionnel ;
- les jugements non attribués ;
- le jargon inutile.

## Phrases

Les phrases doivent être aussi simples que le sujet le permet.

Les paragraphes doivent rester courts.

Une idée principale par paragraphe est préférable.

La concision ne doit pas supprimer une nuance importante.

## Vocabulaire

Les mots précis doivent être privilégiés.

Les formules vagues comme « une situation compliquée », « un important dispositif » ou « de nombreuses personnes » doivent être remplacées par des informations vérifiables lorsqu’elles sont disponibles.

## Voix active

La voix active doit être privilégiée lorsqu’elle permet d’identifier clairement l’acteur.

À éviter :

> Une décision a été prise.

À privilégier :

> Le Gouvernement a adopté la décision.

La voix passive reste acceptable lorsque l’acteur est inconnu ou secondaire.

---

# Titres

Un titre doit :

- refléter fidèlement le contenu ;
- mettre en avant l’information principale ;
- rester compréhensible hors contexte ;
- éviter les ambiguïtés ;
- ne pas exagérer ;
- ne pas promettre plus que l’Article ne contient.

Un titre ne doit jamais :

- transformer une possibilité en certitude ;
- présenter une déclaration comme un fait établi ;
- utiliser une citation tronquée ;
- rechercher uniquement le clic ;
- créer artificiellement de la peur ou de l’indignation.

Les titres interrogatifs doivent rester exceptionnels.

Le système doit préférer une formulation informative lorsqu’une réponse est connue.

---

# Chapô

Le chapô complète le titre.

Il doit apporter une information utile sans répéter exactement le titre.

Il peut préciser :

- le contexte ;
- les personnes concernées ;
- les dates ;
- les conséquences ;
- le niveau d’incertitude.

Il doit rester court.

---

# Citations

Une citation doit être :

- exacte ;
- attribuée ;
- replacée dans son contexte ;
- fidèle à la langue et au sens d’origine.

Une citation traduite doit conserver le sens de l’original.

La traduction ne doit pas rendre la déclaration plus forte, plus élégante ou plus catégorique qu’elle ne l’était.

Les corrections purement grammaticales dans une citation doivent rester exceptionnelles.

Une citation ne doit pas être inventée à partir d’un résumé.

---

# Chiffres, dates et unités

Les chiffres doivent être vérifiés et présentés de manière cohérente.

Les montants doivent préciser la devise lorsque cela est nécessaire.

Les dates doivent éviter les ambiguïtés.

Le jour de la semaine peut être ajouté lorsqu’il facilite la compréhension.

Les heures doivent utiliser une présentation cohérente dans tout le produit.

Les unités doivent respecter le système métrique, sauf lorsqu’une autre unité est indispensable au contexte.

Une comparaison peut être ajoutée pour aider le lecteur, à condition qu’elle soit exacte et non trompeuse.

---

# Noms, fonctions et institutions

Les noms propres doivent être orthographiés conformément aux Sources les plus fiables.

La fonction d’une personne doit être vérifiée au moment de la publication.

Les institutions andorranes doivent être désignées de manière cohérente dans tous les contenus.

Lors de la première mention, le nom officiel peut être accompagné d’une explication en français si nécessaire.

Les mentions suivantes peuvent utiliser une forme courte non ambiguë.

---

# Personnes et vie privée

Le respect de la vie privée doit être proportionné à l’intérêt public de l’information.

Le système doit éviter de publier sans nécessité :

- une adresse personnelle ;
- un numéro de téléphone ;
- une donnée médicale ;
- une information familiale privée ;
- une donnée permettant d’identifier une personne vulnérable ;
- des informations personnelles sans lien avec le sujet.

Les personnes privées doivent bénéficier d’une protection supérieure à celle des personnalités publiques dans l’exercice de leurs fonctions.

---

# Mineurs

L’identité d’un mineur ne doit pas être publiée lorsqu’elle peut lui porter préjudice, sauf justification éditoriale exceptionnelle et validation humaine explicite.

Le système doit éviter les informations permettant une identification indirecte :

- établissement ;
- domicile ;
- identité des parents ;
- photographie reconnaissable ;
- détails familiaux.

Aucune publication automatique ne doit identifier un mineur dans une affaire sensible.

---

# Accidents, violences et décès

Les informations relatives aux accidents, violences et décès exigent une prudence particulière.

Le système doit :

- éviter les détails graphiques inutiles ;
- ne pas spéculer sur les causes ;
- respecter les victimes et leurs proches ;
- vérifier que les proches ont été informés avant d’identifier une victime ;
- attribuer les bilans provisoires ;
- distinguer clairement blessés, victimes et décès confirmés.

Une identité ne doit pas être publiée uniquement parce qu’elle circule sur les réseaux sociaux.

---

# Justice et police

Toute personne mise en cause doit être présentée dans le respect de la présomption d’innocence.

Le système doit distinguer :

- arrestation ;
- placement en garde à vue ;
- mise en examen ou procédure équivalente ;
- accusation ;
- condamnation ;
- appel ;
- décision définitive.

Les termes juridiques doivent être utilisés avec précision.

Un communiqué de police ne doit pas être reformulé comme une décision de justice.

Les sujets judiciaires sensibles nécessitent une validation humaine.

---

# Santé

Les informations médicales ou sanitaires doivent reposer sur des Sources compétentes.

Le système doit éviter :

- les diagnostics ;
- les recommandations médicales improvisées ;
- les liens de causalité non établis ;
- les promesses de traitement ;
- les conseils pouvant mettre le lecteur en danger.

Les risques doivent être présentés sans minimisation ni dramatisation.

Les contenus de santé sensibles ne doivent pas être publiés automatiquement sans règles spécifiques.

---

# Politique et institutions

Les déclarations politiques doivent être attribuées.

Le système doit distinguer :

- une annonce ;
- une proposition ;
- un projet ;
- une décision adoptée ;
- une mesure entrée en vigueur.

Les positions opposées pertinentes doivent être mentionnées lorsqu’elles sont nécessaires à la compréhension du sujet.

L’équilibre ne signifie pas accorder la même valeur à une affirmation documentée et à une affirmation sans preuve.

---

# Entreprises et contenus promotionnels

Un communiqué d’entreprise ne doit pas être repris comme un contenu journalistique neutre sans travail éditorial.

Les affirmations commerciales doivent être attribuées.

Les superlatifs promotionnels doivent être supprimés ou contextualisés.

Les contenus sponsorisés, partenariats et publicités doivent être clairement identifiés.

Un intérêt commercial ne doit jamais être présenté comme une décision éditoriale indépendante.

---

# Images et médias

Une image doit être :

- pertinente ;
- correctement attribuée ;
- accompagnée des droits nécessaires ;
- fidèle au sujet ;
- légendée lorsque le contexte n’est pas évident.

Une image d’illustration ne doit pas être présentée comme une image de l’événement réel.

Les images générées ou modifiées par IA doivent être signalées lorsque leur nature pourrait induire le public en erreur.

Le système ne doit pas altérer une image documentaire d’une manière qui en modifie le sens.

Les recadrages et ajustements techniques doivent rester éditorialement neutres.

---

# Contenus générés par IA

Tout contenu produit par un Agent IA doit respecter les mêmes exigences qu’un contenu humain.

L’origine automatisée d’un brouillon ne réduit pas les obligations de vérification.

Un Agent IA ne doit jamais :

- inventer une information ;
- inventer une citation ;
- inventer une Source ;
- inventer un contexte ;
- masquer une contradiction ;
- présenter une estimation comme une donnée officielle ;
- publier au-delà de son niveau d’autorisation.

La rédaction peut décider d’indiquer publiquement l’usage de l’IA selon le type de contenu et les obligations applicables.

Dans tous les cas, l’utilisation de l’IA doit rester traçable en interne.

---

# Contenus de routine

Certains contenus peuvent être automatisés lorsqu’ils reposent sur des données structurées, stables et suffisamment fiables.

Exemples :

- résultats sportifs officiels ;
- horaires ;
- fermetures de routes ;
- bulletins institutionnels ;
- résultats électoraux officiels ;
- données météorologiques officielles ;
- annonces administratives standardisées.

La publication automatique nécessite :

- une Source approuvée ;
- un format connu ;
- des règles de validation ;
- un niveau de confiance suffisant ;
- une procédure d’échec ;
- une possibilité de retrait immédiat.

---

# Sujets nécessitant une validation humaine

Les sujets suivants exigent par défaut une validation humaine :

- décès et identification de victimes ;
- mineurs ;
- santé sensible ;
- justice ;
- accusations ;
- violence ;
- sécurité publique majeure ;
- élections ;
- conflits d’intérêts ;
- informations issues de Sources anonymes ;
- données personnelles ;
- contradictions non résolues ;
- informations susceptibles de causer un préjudice important.

Cette liste peut être complétée par la rédaction.

---

# Règles de publication automatique

Une Publication peut être automatisée uniquement lorsque :

- le type de contenu est autorisé ;
- la Source est approuvée ;
- les Facts nécessaires sont disponibles ;
- aucune contradiction importante n’est détectée ;
- le niveau de confiance dépasse le seuil défini ;
- les contrôles obligatoires ont réussi ;
- aucune règle n’impose une validation humaine ;
- la Story n’est pas sous contrôle manuel ;
- le canal autorise cette automatisation.

En cas de doute, le système doit suspendre la publication.

L’absence de certitude suffisante doit produire une demande de validation, jamais une improvisation.

---

# Adaptation aux canaux

Le fond de l’information doit rester cohérent sur tous les canaux.

La forme peut être adaptée selon :

- la longueur ;
- le public ;
- le format ;
- le rythme ;
- les contraintes techniques.

Une adaptation ne doit pas :

- supprimer une nuance essentielle ;
- exagérer le titre ;
- transformer une information provisoire en certitude ;
- omettre une attribution importante ;
- déformer le sens pour augmenter l’engagement.

---

# Réseaux sociaux

Les publications sociales doivent rester journalistiques.

Elles doivent éviter :

- le clickbait ;
- les formulations volontairement alarmistes ;
- les questions artificielles ;
- les emojis excessifs ;
- les hashtags inutiles ;
- les appels à la réaction émotionnelle.

Une publication sociale doit pouvoir être comprise sans obliger le lecteur à ouvrir le lien pour corriger une impression trompeuse.

---

# Référencement

Le référencement doit améliorer la visibilité sans dégrader l’information.

Les éléments SEO doivent :

- rester naturels ;
- refléter précisément le sujet ;
- utiliser les noms et termes réellement employés ;
- éviter les répétitions artificielles ;
- ne pas créer de promesse trompeuse.

Le titre éditorial reste prioritaire sur l’optimisation algorithmique.

---

# Droit de réponse

Toute personne ou organisation directement mise en cause doit pouvoir faire connaître sa position selon les règles applicables.

Le droit de réponse ou la réponse reçue doit être :

- attribué ;
- présenté loyalement ;
- intégré sans effacer l’historique ;
- publié dans un délai raisonnable.

Une réponse ne rend pas automatiquement fausse l’information initiale.

Elle devient un nouvel élément du dossier.

---

# Conflits d’intérêts

Les journalistes et responsables éditoriaux doivent signaler les conflits d’intérêts susceptibles d’affecter un traitement.

Le système doit permettre de conserver cette information lorsqu’elle influence :

- l’attribution du sujet ;
- la validation ;
- la publication ;
- le choix des Sources.

Un Agent IA ne doit pas être utilisé pour contourner une règle de conflit d’intérêts.

---

# Embargos

Une information sous embargo ne doit pas être publiée avant l’heure autorisée.

Le système doit conserver :

- la date et l’heure de fin d’embargo ;
- la Source de l’embargo ;
- les restrictions éventuelles ;
- les personnes ou workflows autorisés.

Toute publication automatique doit être techniquement bloquée avant l’expiration de l’embargo.

---

# Archivage

Les Articles, Facts, Sources, Evidences, Publications et Decisions doivent rester accessibles dans l’historique selon les règles de conservation.

Un contenu archivé ne doit pas être présenté comme une information actuelle.

Les Articles anciens peuvent être complétés par une note lorsqu’ils sont susceptibles d’induire le lecteur en erreur en raison d’une évolution ultérieure.

---

# Décisions éditoriales

Toute décision éditoriale importante doit conserver :

- son auteur ;
- sa date ;
- l’objet concerné ;
- le résultat ;
- la justification ;
- les règles appliquées ;
- les informations disponibles au moment de la décision.

Les décisions automatiques doivent être aussi auditables que les décisions humaines.

---

# Gouvernance des règles

Les règles éditoriales peuvent évoluer.

Toute modification doit être :

- datée ;
- justifiée ;
- validée par une autorité éditoriale ;
- versionnée ;
- applicable uniquement à partir d’un moment identifiable.

Le système doit pouvoir déterminer quelles règles étaient actives lors d’une décision passée.

---

# Priorité des règles

En cas de conflit, l’ordre de priorité est le suivant :

1. loi et obligations réglementaires ;
2. sécurité des personnes ;
3. règles éditoriales de la rédaction ;
4. décisions humaines explicites ;
5. règles de Workflow ;
6. recommandations des Agents IA ;
7. optimisation de performance, de diffusion ou de référencement.

Une recommandation technique ou algorithmique ne peut jamais contourner une obligation éditoriale.

---

# Ce que nous refusons

ANDORRE 360 refuse :

- les contenus sans Source identifiable ;
- les citations inventées ;
- les faits non vérifiés présentés comme certains ;
- les titres trompeurs ;
- les corrections silencieuses importantes ;
- la publication automatique de sujets sensibles sans règles adaptées ;
- la copie de communiqués sans traitement journalistique ;
- la traduction littérale produisant un texte artificiel ;
- l’effacement des contradictions ;
- l’opacité des décisions automatisées ;
- la publication pour la seule recherche de trafic.

---

# Résumé opérationnel

Avant toute publication, le système doit pouvoir répondre à ces questions :

```text
Quelle est l’information nouvelle ?

Quelle est sa Source ?

Que dit exactement cette Source ?

Qu’est-ce qui est confirmé ?

Qu’est-ce qui reste incertain ?

Existe-t-il une contradiction ?

Chaque affirmation est-elle traçable ?

Le titre reflète-t-il réellement le contenu ?

Le sujet exige-t-il une validation humaine ?

La publication peut-elle causer un préjudice évitable ?

Le canal choisi conserve-t-il le sens de l’information ?
```

Lorsque l’une de ces questions ne peut pas recevoir une réponse satisfaisante, la publication doit être suspendue ou soumise à validation humaine.

---

# Principe final

L’automatisation doit accélérer le travail éditorial.

Elle ne doit jamais réduire son niveau d’exigence.

Dans ANDORRE 360, une information n’est publiable que lorsqu’elle est suffisamment comprise, vérifiée, contextualisée et traçable.

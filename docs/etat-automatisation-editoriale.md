# État du chantier — automatisation éditoriale

Dernière mise à jour : 2 septembre 2026

## 1. Objet du chantier

L’objectif est d’automatiser progressivement la composition éditoriale des pages d’ANDORRE 360, en commençant par la page d’accueil.

L’IA peut :

- analyser les articles admissibles ;
- attribuer des notes éditoriales ;
- proposer une hiérarchie ;
- produire une simulation de page.

L’IA ne peut pas encore :

- modifier la page d’accueil publique ;
- créer, déplacer ou désactiver une publication ;
- remplacer une sélection humaine ;
- publier directement une proposition simulée.

Le code déterministe reste responsable :

- des exclusions ;
- des seuils ;
- de la déduplication ;
- de la diversité ;
- du respect des capacités des zones ;
- de la protection des choix humains ;
- de la traçabilité ;
- de l’arrêt d’urgence.
